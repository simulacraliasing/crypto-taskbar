# 验证记录

日期：2026-10-30。Windows 11 Build 26300，MinGW-w64 GCC 13.2、CMake、Ninja。

- Release 编译通过，`-Wall -Wextra -Wpedantic` 无警告。输出为 x64 程序，静态链接 C++ 运行库，仅导入 Windows 系统 DLL。
- 离线测试 31 项检查通过，包括配置范围、未知数据源、JSON Pointer 转义、数字字符串、空值/非数字、微小价格、100 币种上限、多币种 URL 合并，以及图形配置保存使用的序列化和回读。
- 用程序实际采用的 WinHTTP 和解析代码访问 CoinGecko、Binance、OKX，三者均取得正数价格和 24 小时涨跌幅。
- 实际查看深色、浅色行情窗口，README 图片来自程序窗口，使用示意行情。
- 实际将鼠标移到真实行情的任务栏显示区，列表自动展开，取得 BTC、ETH、SOL 的完整行情。
- 前一版配置窗口实际检查过无效间隔拒绝、原文件哈希不变、即时生效和备份；这部分存储和校验逻辑继续使用。
- 本地 HTTP 测试接口：24 个币共用一个 URL，每 5 秒只请求一次；列表可滚动到第 24 项。返回 HTTP 503 后保留最后成功价格，显示旧数据和失败状态。

已验证范围是主显示器底部任务栏。多显示器附加任务栏、Windows 10、第三方任务栏和任务栏自动隐藏的所有组合尚未逐项验证。程序按任务栏位置和主题重新定位、绘制；不调整 Windows 主题或应用图标布局。

当前版本新增单币种滚动轮播、三页图形配置、整块区域右键响应，并移除任务栏和托盘图标，已通过本地编译。用户用 Esc 停止了界面自动操作，因此未继续对这些新界面改动进行鼠标和键盘验证。
